这是因为在7108e93这次更新里，移除了字符串id的默认值

![image-20261023193010466](https://raw.githubusercontent.com/infinitepwn/note_picbed/main/image-20261023193010466.png)

具体实现在这里

![image-20261023193051782](https://raw.githubusercontent.com/infinitepwn/note_picbed/main/image-20261023193051782.png)

子模块的 `asttype_generated.py` 里正好对应这条变更：`id: Optional['Identifier'] = "PrimitiveType"` 变成了必填的 `id: 'Identifier'`（`PrimitiveType`、`ArrayType`、`MapType` 都是）。

那这就会导致解析完出现这样的结果

```
// 基准（旧 spec）：id 是字符串
"varType": { "type": "PrimitiveType", "kind": "string", "id": "PrimitiveType" }
// 当前代码：id 是 Identifier 对象
"varType": { "type": "PrimitiveType", "kind": "string", "id": { ... } }
```

也就是说，PR #78 那批 `type-id` 修复把 `id` 的形态改了，基准是按旧 spec 生成的，那之后的回归测试都不会通过了，所以后续开发人员就把这删了

在后面我们发现不止这一个原因

![image-20261023210440603](https://raw.githubusercontent.com/infinitepwn/note_picbed/main/image-20261023210440603.png)

chatbot源码里还放了个key，这个就比较危险了，属于信息泄露

但是实际上既然我们把id改了，那我们就应该生成一个新的基准，然后之后的版本，我们对这个基准做回归测试

用下面的命令生成新的基准

```bash
set -euo pipefail
PP=/Users/infinite/YASA-UAST/parser-Python
TS=$(date +%Y%m%d-%H%M%S)
LEGACY=/tmp/yasa-expected-legacy-$TS
NEW=/tmp/yasa-expected-new-$TS
cd "$PP"

.venv313/bin/python - "$NEW" <<'PY'
import sys, json
from pathlib import Path
sys.path.insert(0, 'test')
import run_regression as r

out_root = Path(sys.argv[1])
src = Path('test/chatbot_backend')
files = r.collect_sources(src)

def rel_sourcefile(node, value):
    if isinstance(node, dict):
        for k, v in list(node.items()):
            if k == 'sourcefile' and isinstance(v, str):
                node[k] = value
            else:
                rel_sourcefile(v, value)
    elif isinstance(node, list):
        for item in node:
            rel_sourcefile(item, value)

for p in files:
    rel = p.relative_to(src)
    out = (out_root / rel).with_suffix('.json')
    out.parent.mkdir(parents=True, exist_ok=True)
    ok, err = r.parse_single_file(str(p), str(out), verbose=True)
    if not ok:
        raise SystemExit(f"parse failed: {rel.as_posix()}: {err}")
    data = json.loads(out.read_text())
    rel_sourcefile(data, rel.as_posix())
    out.write_text(json.dumps(data))
print(f"generated={len(files)}")
PY

mv test/chatbot_backend_expected "$LEGACY"
mv "$NEW" test/chatbot_backend_expected

if .venv313/bin/python test/run_regression.py; then
  echo "VERIFY_OK legacy=$LEGACY"
else
  rm -rf test/chatbot_backend_expected
  mv "$LEGACY" test/chatbot_backend_expected
  exit 1
fi
```
