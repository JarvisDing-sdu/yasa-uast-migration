## 构建方式及限制

- Node 源码运行：v22.22.1；pkg 实装版本 5.8.1，目标 node18-linux-x64（基座 v18.5.0）。
- 使用真实 TypeScript CLI 编译，再执行 PHP wasm 路径补丁及真实 pkg CLI；本机 node_modules/.bin 中部分包装文件为空，未使用这些空入口。
- 命令：`node node_modules/pkg/lib-es5/bin.js . --targets node18-linux-x64 --options max-old-space-size=11264 --output /tmp/yasa-acceptance-linux`。
- SQLite addon 从 engine/native/better-sqlite3/linux-x64/better_sqlite3.node 放置到二进制相邻的 `.native/better-sqlite3.node`。
- 二进制 `/tmp/yasa-acceptance-linux` 约 365 MiB；仍有 24 条 Failed to make bytecode 警告，但两套 Python 扫描均正常且无严重性能回退。
- 构建警告还包括缺失 Go 解码器和 build-version.json。本次为针对 Python 的验收构建，未声称 build.sh 全流程、Go 功能、macOS 平台或正式发布元数据通过。
- 四类星号展开最小复现通过打包二进制 dumpAST，输出非 null；不是队员原始四个完整 PyTorch 文件的验收。
